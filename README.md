Tutorials teach you a tool. They don't turn into a portfolio, and a pile of bookmarks doesn't turn into a skill set.

The **Data Science & AI Workspace** is a guided self-study system built in Notion. It takes you from Python foundations to modern AI, and every step ends in something you can build, test and put on GitHub.

> **Not a course. Not another PDF.** A system for learning, practicing and building.

---

## 🧩 What's inside

| | |
|---|---|
| 🗺️ **Structured roadmap** | 4 modules, 27 submodules: Python & Data Foundations → Math & Stats → Core Machine Learning → AI & Modern ML. Always know what to learn next. |
| 📚 **Curated resources** | Selected free resources matched to every stage, so you don't waste weeks searching. |
| 🛠️ **Practice built in** | Practical exercises and self-checks throughout, so knowledge turns into ability. |
| 🏗️ **5 capstone projects** | Substantial projects that combine skills. Put them on GitHub, deploy them, discuss them in interviews. |
| 🎯 **Interview quiz simulator** | 35 questions across 7 topics: Python & Pandas, SQL, Statistics & Probability, Core ML, Model Evaluation, Deep Learning & NLP, Applied Case & Product Sense. |
| ⏱️ **Time tracker** | Make your progress visible and build consistency. |
| 🌑 **Dark terminal theme** | Built for long study sessions. |
